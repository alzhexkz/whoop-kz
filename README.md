# WHOOP на русском 🟢

Компаньон-приложение для WHOOP Peak с полным русским интерфейсом. Устанавливается на телефон как приложение (PWA).

## Что показывает

- **Восстановление**: %, ВСР, ЧСС покоя, SpO₂, температура кожи (Peak), вариабельность SpO₂ (Peak), долг сна
- **Сон**: фазы (глубокий/REM/лёгкий), время отхода и подъёма, циклы, пробуждения, стабильность
- **Нагрузка**: strain, зоны пульса по каждой тренировке, калории, история за 7 дней

## Деплой: пошаговая инструкция

### Шаг 1 — Получи Client ID на WHOOP

1. Зайди на https://developer.whoop.com
2. Создай приложение (можно назвать "WHOOP RU")
3. Скопируй `Client ID`

### Шаг 2 — Вставь Client ID в код

Открой `src/App.jsx`, найди строку 4 и замени:

```js
const WHOOP_CLIENT_ID = "YOUR_CLIENT_ID";
// замени на:
const WHOOP_CLIENT_ID = "твой_client_id_здесь";
```

### Шаг 3 — Задеплой на Vercel (бесплатно)

**Вариант А — через сайт Vercel (проще):**
1. Создай аккаунт на https://vercel.com
2. Загрузи папку `whoop-ru` на GitHub (или используй Vercel CLI)
3. Подключи репозиторий в Vercel → он соберёт и задеплоит автоматически

**Вариант Б — через терминал:**
```bash
npm install
npm run build
npx vercel --prod
```

### Шаг 4 — Укажи Redirect URI в WHOOP Developer

После деплоя у тебя будет URL вида `https://whoop-ru.vercel.app`.
Зайди обратно на developer.whoop.com → твоё приложение → добавь Redirect URI:
```
https://whoop-ru.vercel.app/
```

### Шаг 5 — Папа устанавливает приложение

Папа открывает сайт в браузере телефона:

**iPhone (Safari):**
1. Открыть сайт в Safari
2. Нажать кнопку "Поделиться" (квадрат со стрелкой вверх)
3. Выбрать "На экран «Домой»"
4. Нажать "Добавить"

**Android (Chrome):**
1. Открыть сайт в Chrome
2. Нажать три точки (меню)
3. Выбрать "Добавить на главный экран"
4. Нажать "Добавить"

После этого приложение появится на главном экране как обычное — без браузера и адресной строки.
